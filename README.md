# DroneProto

DroneProto는 여러 플레이어가 한정된 부품을 나눠 사용해 각자의 드론을 조립하고, 함께 보스를 공략하는 멀티플레이 레이드 게임 프로토타입이다.

## 게임 소개

플레이어는 로비에서 드론의 코어와 무기를 선택한 뒤 레이드에 참가한다. 전투에서는 드론을 직접 움직이고 공격과 회피를 사용해 보스의 패턴에 대응한다. 레이드가 끝나면 플레이 기록과 점수를 리포트로 확인할 수 있다.

## 주요 기능

- 호출부호 입력과 기본 조작 튜토리얼
- 여러 플레이어가 함께 사용하는 드론 부품 선택
- 이동, 공격, 회피를 활용한 보스 전투
- 보스 상태와 남은 시간을 보여주는 전투 화면
- 플레이 결과와 보너스 점수를 보여주는 Drone Report

## 개발 상태

로비 입장부터 튜토리얼, 부품 선택, 보스 전투, 결과 확인까지의 기본 흐름이 연결되어 있다. 현재는 기능과 화면 구성을 다듬고 최종 연출과 에셋을 보완하는 단계다.

프로젝트는 Unreal Engine 5.7로 개발 중이며, 주요 기능은 에디터 실행과 자동화 테스트로 확인하고 있다.

## 협업 방법

### 작업 규칙

- 작업 시작 전 최신 내용을 `pull`한다.
- 수정할 맵이나 주요 에셋을 팀원에게 알린다.
- 같은 `.uasset`이나 `.umap`을 동시에 수정하지 않는다.
- 실제로 수정한 파일만 저장하고 커밋한다.
- 에셋 이름 변경·이동·삭제는 먼저 공유한다.
- 충돌한 에셋은 직접 병합하지 않고 한쪽 작업을 다시 적용한다.
- 커밋 전 빌드 또는 에디터 실행으로 작업 결과를 확인한다.

### 커밋 메시지

```text
영어타입: 한글 작업 내용
```

| 타입 | 용도 |
| --- | --- |
| `feat` | 새로운 기능이나 동작 추가 |
| `fix` | 잘못된 동작이나 오류 수정 |
| `refactor` | 기능 변화 없이 코드나 구조 정리 |
| `ui` | Widget, 버튼, 문구 등 UI 작업 |
| `asset` | Blueprint, 맵, 애니메이션, 사운드 등 에셋 작업 |
| `test` | 테스트 추가 또는 수정 |
| `docs` | 기획서와 문서 수정 |
| `chore` | 설정, 폴더 정리, 이름 변경 등 기타 작업 |

- 한 커밋에는 가능한 한 하나의 작업만 담는다.
- 메시지만 보고 무엇을 바꿨는지 알 수 있게 작성한다.
- `작업`, `수정`, `업데이트`, `최종`처럼 모호한 표현만 사용하지 않는다.

```text
ui: 부품 선택 화면 버튼 배치 수정
ui: 보스 체력바 크기와 정렬 조정

asset: 프롤로그 카메라 연출 추가
asset: 테스트 맵에 드론과 보스 배치

test: 회피 경계 자동화 테스트 추가
docs: 프롤로그 작업 순서 정리
chore: 에셋 폴더와 파일 이름 정리
```

</details>

### 커밋 전 확인

- 수정한 기능을 직접 확인했는가?
- Blueprint 컴파일 또는 C++ 빌드 오류가 없는가?
- 관계없는 파일이 포함되지 않았는가?
- 다른 사람이 작업 중인 에셋을 수정하지 않았는가?
